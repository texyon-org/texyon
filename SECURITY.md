# Security

If you find a security problem in TeXyoN, please email texyon@yendric.be
instead of opening a public issue. I'll reply within a few days and keep you
posted until it's fixed.

Things worth reporting include a document that can read or write files outside
its project, run commands, crash the engine in a way that corrupts memory, or
escape the web editor's worker.

Only the latest release gets security fixes.
